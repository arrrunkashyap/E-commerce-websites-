# Simple E-Commerce Website

A beginner-level e-commerce website built using HTML, CSS, and JavaScript.
## Features

- Product listing
- Add to Cart
- Remove from Cart
- Cart counter
- Total price calculation
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
